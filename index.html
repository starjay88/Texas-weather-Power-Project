⚡ Texas ERCOT Grid & Weather Open Data Portal 🌡️

Real-time ERCOT grid stress and weather disaster monitoring system.

* All times are displayed in Texas Local Time (Central Time).

Column Name Description Data Type Unit
Time Timestamp of the recorded data Datetime (ISO 8601) UTC / CT
Temperature Surface air temperature in Texas Float Fahrenheit (°F)
Electricity Demand Total ERCOT power grid demand Integer Megawatt-hours (MWh)
Weather Condition Short text description of weather (e.g., Mostly Clear) String -

⚡ Power: U.S. Energy Information Administration (EIA) API
